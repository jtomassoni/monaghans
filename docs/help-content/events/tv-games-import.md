# Import Avalanche & Nuggets Schedules

Pull a full Avalanche or Nuggets season onto the calendar in one click — labeled as games we'll have on — without creating Broncos-style pot luck events.

## How to Import or Refresh

1. Go to [Calendar](/admin)
2. Click **TV Games**
3. Choose **Import season** (first time) or **Refresh** (when ESPN updates times)
4. Optionally check **Deactivate games that disappear from the ESPN schedule**

Each team can be refreshed on its own whenever the league moves a game.

## What Gets Created

- Regular calendar events (not football pot luck games)
- Title like `Avalanche vs. Kings` or `Nuggets vs. Lakers`
- Description that says we'll have the game on at Monaghan's
- Visible on the public events page under **Games We'll Have On**

## Editing After Import

Open any imported game on the calendar or list and edit it like a normal event — title, time, description, or status.

Refresh **will not overwrite** games you've changed by hand. Only untouched imports get updated from ESPN.

## Tips

- Run import once per team at the start of the season, then refresh if tip-offs move
- Delete or deactivate a game if you won't have that one on
- Broncos watch parties still use **New → Football Game** (separate flow)
