# Creating One-Time Events

Create single events that don't repeat.

## How to Create

### From Calendar

1. Go to [Calendar](/admin)
2. Click the date
3. Select **"New Event"**
4. Fill details and save

### From Events List

1. Go to **Calendar**
2. Switch to **List View**
3. Click **"New Event"**
4. Fill details and save

### Quick Actions

1. Open **Quick Actions** menu (any admin page)
2. Select **"New Event"**
3. Fill details and save

## Football Games

Add Broncos watch-party games from Calendar → **New** → **Football Game**.

Each game is a regular calendar event you can edit later. Choose the opponent from the team list, then set the kickoff time and the house meal for the pot luck buffet (tacos, lasagna, and so on). The form and homepage hero pick up that team's colors. The next upcoming game highlights the house meal, kickoff, and opponent, and invites guests to bring a side or dessert to share.

## Avalanche & Nuggets (TV Games)

For a full season of games we'll have on — without pot luck setup — use Calendar → **TV Games**. Import or refresh Avalanche and Nuggets schedules from ESPN. After import, edit any game like a normal event; refresh leaves hand-edited games alone. See [Import Avalanche & Nuggets Schedules](/admin?view=list) help for details.

## Event Details

### Required

- **Title**: Event name (e.g., "Live Music Night")
- **Start Date & Time**: When it begins
- **End Date & Time**: When it ends (skip for all-day events)

### Optional

- **Description**: Event details
- **Venue Area**: Location (e.g., "Main Bar", "Patio")
- **Tags**: Categories (e.g., "music", "sports")
- **All Day**: Check if event lasts all day
- **Image**: Upload event image
- **Status**: Active (visible) or Inactive (hidden)

## Status

- **Active**: Visible on calendar and website
- **Inactive**: Hidden (useful for drafts)

## Tips

- Use tags to organize similar events
- Add venue area so customers know where to go
- Include important details in description (cover charges, age restrictions)
- Upload images to make events stand out
